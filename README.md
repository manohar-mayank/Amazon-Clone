This project was built approximately two years ago as part of my journey to learn and practice front-end web development.

The main goal was to recreate the structure and layout of a modern e-commerce website using fundamental web technologies.

- CSS styling and layouts

- Responsive layout techniques
- Flexbox
- Basic UI design
- Working with images and assets
